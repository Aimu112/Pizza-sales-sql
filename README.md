# 🍕 Pizza Sales Data Analysis (SQL Project)

An end-to-end relational data analysis project evaluating sales performance, ordering patterns, revenue growth, and category trends for a pizza business using advanced SQL queries.

---

## 📋 Project Overview
This project explores a complete relational database to extract actionable business insights. By writing and executing complex SQL queries, the analysis uncovers top-performing products, peak customer ordering times, revenue contributions across categories, and daily purchasing behavior.

---

## 🗄️ Relational Database Schema
The underlying database consists of **4 interconnected tables**:
1. **`orders`**: Tracks operational timestamps (`date`, `time`).
2. **`order_details`**: Line-item transaction data mapping orders to specific items and quantities (`quantity`).
3. **`pizzas`**: Item-level pricing (`price`) and sizing variations (`size`) linked via `pizza_id`.
4. **`pizza_types`**: Categorical metadata including product names (`name`), categories (`category`), and ingredients.

---

## 🔍 Key Business Questions Addressed
* **Sales & Revenue Performance:** Calculating total revenue generated, identifying top-selling pizzas by revenue and quantity, and finding the highest-priced items.
* **Operational Trends:** Analyzing peak ordering hours, daily order volumes, and average pizzas ordered per day.
* **Product Mix & Category Insights:** Determining category-wise distribution, percentage contributions of each pizza type to total revenue, and cumulative revenue growth over time.

---

## 🛠️ Tech Stack & Tools
* **Database Management System:** MySQL / MySQL Workbench
* **Query Language:** SQL (Joins, Aggregations, Subqueries, CTEs, Window Functions)
* **Presentation & Documentation:** Canva (Portfolio Deck Design)
